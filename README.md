# Bela Zara Magazine | version prête pour Render

Blog indépendant au style graphique noir, blanc et rouge.

- Installation locale : `npm start` avec Node.js 22.13+.
- Publication sur Render : lire `DEPLOIEMENT-RENDER.md`.
- Administration : `/admin` après configuration privée de `ADMIN_PASSWORD`.
- Données : SQLite et médias enregistrés sous `DATA_DIR` (nécessite un disque durable en ligne).

Les publications présentes au premier lancement sont des contenus fictifs de démonstration.
